# Symulator Ruletki

Projekt zaliczeniowy realizowany w ramach przedmiotu **Narzędzia Pracy Grupowej** (AGH WEAIiIB).
Aplikacja konsolowa symulująca grę w ruletkę, tworzona w zespole 5-osobowym z wykorzystaniem metodyki SCRUM.

## Struktura Repozytorium
Projekt został zorganizowany zgodnie z dobrymi praktykami dla języka C/C++:
* `src/` - pliki źródłowe
* `include/` - pliki nagłówkowe

## Moduły Systemu (Gałęzie)
* **GameManager** - główna pętla sterująca rozgrywką.
* **Wheel** - silnik losujący i klasyfikator pól.
* **Wallet** - wirtualny portfel gracza i zarządzanie saldem.
* **BetManager** - system rozliczania zakładów i mnożników.
* **UI** - interfejs konsolowy, obsługa wejścia/wyjścia i walidacja danych.
